# AI Resume Screening System

An AI-powered Resume Screening System built using Python and NLP concepts.

## Features

* Upload PDF resumes
* Extract resume text
* Skill matching system
* Resume match percentage
* Modern GUI interface

## Technologies Used

* Python
* Tkinter
* PDFPlumber
* NLP
* Scikit-learn

## How to Run

1. Install requirements:
   pip install -r requirements.txt

2. Run the application:
   python main.py

## Project Workflow

Resume PDF → Text Extraction → Skill Matching → Match Score
